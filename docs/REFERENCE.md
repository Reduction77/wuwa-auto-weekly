# 参考说明

参考项目：[OK-Wuthering-Waves](https://github.com/ok-oldking/ok-wuthering-waves)。

## 参考范围

- `src/task/GardenTask.py`：周常入口、祝福及奖励选择、商店、阶段结算与整局结束流程。
- `src/task/MultiAccountDailyTask.py`：原生 ComboBox 账号读取、选择通知、登录与返回登录流程。
- 返回登录时，按游戏界面的实际按钮和状态转移推进。

本项目独立组织窗口输入、OCR 页面判定、任务控制、SQLite 记录与桌面界面。运行时不导入参考项目代码，也不加载参考项目的图片模板。

## 本项目的差异

- 当前仅支持国服官服的已保存手机号账号。
- 账号切换使用标准 Windows 控件消息，并读取控件当前选中项核验；登录点击后等待页面转移，有限重试。
- 通过角色标识绑定验证账号身份，发现冲突停止。
- 结束一局后回到准备页面，复查实际周度进度；未满则继续。
- 达到 6000 后按当前规则点击两次奖励领取位置，不声称逐项核验领取结果。

`garden/assets/` 中的小图由本机游戏截图裁剪，用于识别按钮，不来自参考仓库。游戏画面权利仍归原权利人。开发过程中下载的第三方参考资料仅存于被忽略的 `data/reference-review/`，不随源码发布。
